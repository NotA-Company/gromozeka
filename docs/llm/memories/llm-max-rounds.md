# LLM maxRounds round-limit (`generateTextViaLLM`) — added 2026-07-16

Archived durable notes from [`../teamlead-memory.md`](../teamlead-memory.md) (extracted 2026-07-18). See the live compact memory there for cross-cutting rules and workflow lessons.

`LLMService.generateTextViaLLM` (`internal/services/llm/service.py`) takes `maxRounds: Optional[int] = DEFAULT_MAX_ROUNDS` (=32, in `internal/services/llm/constants.py`; re-exported via `__init__.py`). Bounds the tool-calling loop. `None`=unlimited (legacy), `0`=drop tools on first call, negative→`ValueError`. `roundN` is 0-based, increments after each `generateText`; once `roundN >= maxRounds` (`budgetExhausted`): drop `tools=[]`, clear `filteredToolNames`, disable healing, inject a steering directive, force-terminate within one extra round.

- **KEY GOTCHA — `tools=[]` ALONE DOES NOT STOP TOOL EXECUTION.** The execution guard is `toolCall.name in filteredToolNames` (resolved ONCE before the loop via `_resolveTools(useTools)`), and tool-call healing (`_tryHealToolCall`) accepts on the GLOBAL `self.toolsHandlers` registry (NOT `filteredToolNames`/local `tools`). So dropping only `tools` leaves a bypass: a model emitting tool-call-shaped FINAL text gets healed → executes via the stale allowlist. To actually bound the loop you must ALSO clear `filteredToolNames`, gate healing (`and not budgetExhausted`), and gate the TOOL_CALLS execute-branch (`and not budgetExhausted`) so post-budget TOOL_CALLS→`break`. Together these make the loop terminate within exactly one post-budget round for every `ModelResultStatus`.
- **`ModelRunResult.roundLimitHit: bool`** (`lib/ai/models.py`, `__slots__` field, default False): set True on ANY post-budget termination (regardless of status) + a service-level `logger.warning`. Lets callers detect an incomplete result. Backward-compatible (defaulted slot). Not in `ModelRunResult._STR_RENDERERS`, so the default `__str__` rule applies: dropped from `__str__` when `False` (the default — `False`-valued slots are skipped like `isFallback`/`isToolsUsed`) but rendered as `roundLimitHit=True` when set.
- **Post-budget fallback synthesis** fires ONLY for empty `FINAL` and post-budget `TOOL_CALLS` (status `in (FINAL, TOOL_CALLS)`); `ERROR`/`CONTENT_FILTER`/`UNKNOWN` propagate with original status + empty text so callers detect the failure. Open edge (deferred 2026-07-16): empty `TRUNCATED_FINAL`/`PARTIAL`/`UNSPECIFIED` also propagate (callers degrade gracefully; could fold `TRUNCATED_FINAL` into the set later).
- **Steering directive folds into the LEADING system message** (or `role="user"` when none), NOT a mid-stream `system` message — YC SDK (`yc_sdk_provider._convertMessages`) historically rejects/ignores mid-stream system. Safe + non-compounding because `condenseContext` keeps the leading system at index 0 AND only one post-budget iteration exists.
- **Callers:** memory-refinements loop (`user_memories._runSingleRefinement`) inherits the default 32 (intended per user TODO "memory refinement: hard limit on steps, 32") and surfaces cap-hit via a `roundLimitHit` check + `logger.warning`. Chat path (`llm_messages.py`), `divination.py` (degrades gracefully on non-FINAL), `dev_commands.py` use the default unchanged.
- **Tests:** `tests/services/llm/test_max_rounds.py` (11) + a `test_user_memories.py` cap-hit test. Pattern: instance-mock `self.condenseContext` (passthrough) + `self.generateText` (scripted `ModelRunResult` list); real `ModelRunResult`; dummy `registerTool` + `useTools=True`. Infinite-loop guard: finite `side_effect` → unbounded loop raises `StopAsyncIteration` (fail-loud, not hang). Healing-bypass regression payload is a fenced JSON block `{"name":"<toolName>","arguments":{}}` which triggers `_matchTextForJSONToolCall`.
- **Layering:** LLM-service constants live in `internal/services/llm/constants.py` (precedent `internal/services/queue_service/constants.py`, `storage/utils.py`), NOT `internal/bot/constants.py` — `bot→service` is the normal edge; a `service→bot` import for a service-owned constant is a layering inversion. `TOOLS_DEFAULT_DICT_KEY` (= `"default"`) now also lives in `internal/services/llm/constants.py` (re-exported via `internal.services.llm`): although it is a shared handler/service contract symbol, the handlers that build the `useTools` dict (`llm_messages.py`) import from the service layer anyway, so consolidating it there removes the last `internal.services.llm → internal.bot.constants` edge with no cycle. Only `ToolName` (the per-tool StrEnum) remains in `internal/bot/constants.py`.
