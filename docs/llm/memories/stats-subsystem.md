- API: abstract `StatsStorage.record(stats: dict[str, float|int], *, consumerId, labels, eventTime)` (async, best-effort never-raises) + `aggregate(*, limit=1000, orphanTimeoutSeconds=3600) -> int`; `NullStatsStorage` no-op; `DatabaseStatsStorage` in `lib/stats/sql_storage.py` (constructed in `main.py` with hardcoded eventTypes `"llm_request"` and `"stt_request"`, gated by `[stats] enabled`, default false in `configs/00-defaults/stats.toml`, true in `configs/common/10-stats.toml`; data-source overrides `llm/stt-stats-data-source`).
- Schema (migration_016): `stat_events` raw append-only log (UUID event_id, processed/claimed_at for claim-based aggregation, orphan reclaim) + `stat_aggregates` PK(event_type, period_start, period_type, labels_hash, metric_key); buckets hourly/daily/monthly/total; per-consumer AND `__global__` rollup; labels_hash = MD5 of canonical labels JSON.
- Only consumers today: `lib/ai/abstract.py` (2 record sites: generation attempts + embeddings; stats: `generation_{type}`, request_count, input/output/total tokens, is_error, `status_*`, elapsed_time; labels: modelName/modelId/provider/generationType/status[/error]) AND **STT — fully implemented at `lib/stt/abstract.py:264-275` (`_recordStats`, called from `transcribe()`; stats: generation_stt, request_count, audio_duration_ms, elapsed_time, is_error, `status_*`)**. Plumbing path: main.py → STTService.initialize(statsStorage=...) → provider constructor. Searching only `internal/services/stt/` misses it — the recording lives in `lib/stt/`.
- **Rollup semantics:** `__global__` rollup replaces ONLY the `consumer` label, keeps all others in labels_hash → "global" = per-label-combo across consumers, NOT a true all-dims total. `consumerId` merges into `labels["consumer"]` before hashing (MD5 of sorted-keys compact JSON). Aggregation is SUM-only, periods hourly/daily/monthly/total as ISO strings (total = epoch sentinel). True-global totals need post-query SUM or a future stripped-labels rollup pass.
