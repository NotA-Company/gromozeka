# Documentation index

Gromozeka's documentation lives in this tree. Links below are grouped by
audience; each entry is a pointer to the authoritative document, not a copy
of its content.

## For humans

- [`../README.md`](../README.md) — project overview: features, quick start,
  minimal configuration, run commands.
- [`guides/getting-started.md`](guides/getting-started.md) — start here:
  project and architecture overview, directory structure, quick reference.
- [`guides/`](guides/) — topic guides for developers: handlers, database,
  services, configuration, libraries, quality & testing, operations.
- [`developer-guide.md`](developer-guide.md) — full map of the guides above
  (the former monolithic contributor guide, split into `guides/` on

## Excluded and archived material

- [`archive/`](archive/) is historical only: completed plans, superseded
  designs, and stale point-in-time reports. Archived files are never updated
  for drift.
- `archive/` and `other/` are both excluded from the markdown-mcp index
  (the `exclude` list in [`../.markdown-mcp.toml`](../.markdown-mcp.toml)):
  they are not indexed and do not appear in search results.
- `other/` is reachable only via direct file access through its
  [README](other/README.md).
- The old `suggestions/` lists (improvements / refactoring / simplification)
  were archived as stale point-in-time audits. Fresh suggestion lists are
  regenerated by asking an agent to run a new audit pass against the current
  tree — they are not maintained as living documents.
